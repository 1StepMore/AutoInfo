# AutoInfo · 目标与任务（给 coding agent · 2026-11-05 夜）

> 定位：通用信息追踪 / 知识库平台 —— 多领域采集 → 抽取 → 沉淀。
> 以下是**要达成的目标与任务**。**具体怎么实现、怎么拆解，交给 coding agent 判断**，这里不规定路径。

## 短期目标

**1. 收录的「新增」必须是真新鲜、且不重复。**
- 现状：多个领域的"近 7 天新增"里，大部分其实是旧文章被重复收录（例如 ai-commercial 近 7 天新增 603 条里有 555 条是旧内容），等于把陈旧内容当新鲜。
- 目标：新增 = 真正的新内容；旧文重复不再计入；转载/重复能被识别。

**2. 数据源要么正常干活、要么明确停用，不留半状态。**
- 现状：有源因缺凭证被跳过、也有源采集失败，悬在那儿。
- 目标：每个源都是"正常采集"或"显式停用"二选一，不再有"缺凭证 / 失败"的模糊状态。

**3. 质量问题可观测、可归因。**
- 现状：质量检查汇总会报"若干断言失败"，但看不出是哪几条、落在哪个领域/单元。
- 目标：任一条失败都能定位到具体位置和原因，并把失败清零。

## 中期目标
- 新鲜度治理：把"有真语料"和"内容是新采的"分开度量、分开告警。
- 采集源健康与生命周期：该恢复的恢复、该退役的退役，失败能自愈或降级。
- 同一内容跨站转载的重复治理。
- 文档与实现对齐（规格别落后于代码）。

## 边界
- **不碰 AutoMedia**（另一条线在做）。
- 实现方向、技术选型、拆解步骤由 coding agent 决定；这里只给目标。
