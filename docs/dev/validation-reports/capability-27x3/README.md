# Capability verification 27×3 — evidence pack

Evidence for the plan `.omo/plans/capability-verification-27x3.md`: the 7×18
cell matrix audited for the three verification domains (`medical-research`,
`language-learning`, `ai-commercial`), the 8 output formats structurally
checked (L2), and every claim below regenerable by a single command.

This directory holds **indexes, tables and logs only**. Product artifacts stay
in gitignored `outputs/`; nothing generated is committed here.

## Layout

| Path | What it holds | What it proves |
|---|---|---|
| `runs/<domain>/<combination>.md` | One row per produced product: command, artifact path, size, L1/L2 verdicts, cost | A cell is *produced* because a product artifact exists and passed the structural check — not because a function exists |
| `runs/index.md` | Per-domain summary table (cells produced / gap / unconfigured) | Coverage arithmetic is re-derivable from the artifact list |
| `logs/` | Raw command output: collection, processing, suite baselines, KB repair | Every number in the tables came from a captured run |
| `logs/kb-purge-2026-10-27.md` | Files and index rows deleted before the rebuild | The KB started clean; no synthetic residue inflates a count |
| `logs/collect-*.log`, `logs/collect-delta-*.md` | Raw collector output plus a delta table | Which source produced how many items, and the exact error for every source that produced none |
| `source-diagnosis.{csv,md}` | Generated classifier tables (78 spec pairs) | Each source's bucket, recommendation and blocker, regenerated by `scripts/source_diagnosis.py` |
| `matrix.json`, `matrix.md` | The 27x3 run (81 rows) | Authoritative row-per-cell verdicts: reached layer, keyed/unkeyed flag, artifact path, duration, cause chain |
| `l0-l1-baseline.md`, `logs/l0-baseline-*.log`, `logs/l1-baseline-*.log` | L0 gate + L1 battery run before the matrix | The pre-run defect count every later number is compared against (medical-research 55/52), and proof the L1 judge escalated rather than passed without a key |

## Regenerate each table

```bash
# Coverage matrix (cell states) — writes outputs/coverage-matrix/
.venv/bin/python scripts/coverage_matrix.py --evidence . --llm-available

# Without an LLM key (L3 blocked, shown as unconfigured rather than passed)
.venv/bin/python scripts/coverage_matrix.py --evidence .

# Per-source diagnosis (78 spec pairs, bucket + recommendation)
.venv/bin/python scripts/source_diagnosis.py

# Structural (L2) check of one product
.venv/bin/python scripts/format_structure.py outputs/<domain>/<file> --json

# Agent battery (L1, opt-in)
.venv/bin/python scripts/agent_review/battery.py outputs/<domain> --semantic

# KB index/file parity
.venv/bin/python -m pytest tests/validation/test_kb_index_parity.py -q
```

## Number discipline

- A cell counts as **produced** only when `scripts/format_structure.py`
  passes on a real artifact under `outputs/`.
- **unconfigured** (no key, no source) and **gap** (capability missing) are
  different failures and never collapse into one bucket.
- Structural checks are L2. L1 (semantic judging) is opt-in; L0
  (`scripts/quality_gate.py`) stays blocking.
- Every log line is a captured stdout/stderr, never a hand-written summary.
