# docs/user/ — 用户旅程与用户手册

> 此目录是用户旅程文档的骨架（方针 A8；User 黑盒验收的旅程来源）。内容留给 Owner / 后续旅程编写填充；
> 执行者只建骨架，不代拟旅程内容（期望层纪律：期望定义 = Owner）。

## 约定

- 每个旅程一份文档：`journeys/<旅程名>.md`，字段 = 前置 / 步骤（仅终态断言） / 期望终态 / 证据类型（对齐 `.agents/expectations/checkpoints.md` 口径）。
- 旅程的**执行**放在 `tests/e2e/features/`（挂验证场景 ID）；本目录只放**定义**。
- 公开入口口径：MCP 工具 / CLI 命令 / 交付产物（B1/B2/B3 用户模型见 `docs/dev/specs/user-lifecycle-definition.md`）。
